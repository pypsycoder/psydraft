# Ассистент выбора антидепрессантов

Автономный врачебный прототип версии 0.3. Снимок клинической базы: 30.09.2026; исправления безопасности и интерфейса — 13.10.2026.

## Запуск

Скачайте `antidepressant-assistant.html` и откройте его в современном браузере. Сервер, сборка и установка зависимостей не нужны. Просмотр HTML на странице GitHub показывает исходный код; для запуска нужен скачанный файл.

## Возможности

- Кликабельный список незаполненных данных открывает соответствующий раздел формы.
- При депрессии: выбор основного руководства (КР РФ, NICE, VA/DoD, CANMAT), тяжесть эпизода, выраженность симптомов и главные мишени.
- История нескольких курсов: препарат, диагноз, эпизод, доза, длительность, приверженность, адекватность, ответ и нежелательные эффекты.
- Раздельные объяснения места в терапии, симптомных аргументов, рисков и индивидуального опыта; различия руководств показаны отдельно.
- Дополнительные маршруты для ГТР, панического расстройства, ОКР и ПТСР.
- Импорт и экспорт JSON, печать, учебные примеры, источники и журнал правил.

## Интерпретация

Частичный порядок опций — проектное правило без суммы баллов и без прогноза вероятности ремиссии. Противопоказания имеют приоритет над благоприятным совпадением симптомов. Инструмент не рассчитывает дозы, переходы, комбинации и полный набор взаимодействий. КР и инструкции конкретного препарата необходимо сверять отдельно.

Прототип не прошёл клиническую валидацию. В предыдущей разработке выполнены проверки клинических сценариев и модели DOM; проверка в настоящем браузере остаётся невыполненной. При переносе в этот репозиторий проверены синтаксис встроенного JavaScript и точное совпадение содержимого HTML.

## Клинические данные

Профили не передаются в сеть и автоматически не сохраняются. Данные существуют в памяти страницы; экспорт JSON выполняется явно пользователем. Экспортированные клинические профили не следует добавлять в репозиторий. Внешние ссылки на источники открываются отдельно.

## Исправления версии 0.3

- Противопоказания ТЦА при тяжёлых заболеваниях печени, недавнем ИМ, блокадах и аритмиях теперь исключают препарат из маршрута.
- Общий сердечный анамнез требует уточнения; он не приравнивается автоматически к конкретному противопоказанию.
- Для кломипрамина уточняются узкоугольная глаукома и задержка мочи.
- Возраст ≥75 лет исключает агомелатин по рекомендации европейского SmPC; причина выделена как возрастное ограничение.
- Противоречие между внесёнными курсами и отметкой «курсов не было» требует исправления.
- Добавлены видимый дисклеймер и палитра PsyDraft из `frontend/psychstatus/src/css/base.css`.
- Профили версий 0.1 и 0.2 импортируются без домысливания уточняющих данных.

## Проверки безопасности

В `tests/safety-scenarios.js` зафиксированы 113 регрессионных проверок, включая противопоказания, неопределённые данные, отсутствие ложного автоматического запрета и совместимость профилей. Это проверка программы, не клиническая валидация. При подготовке версии проверки движка выполнены без ошибок; запуск страницы тестов в настоящем браузере ещё требуется.

Для проверки в браузере из каталога `frontend/antidepressants` запустите:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/tests/safety-scenarios.html`. Сервер нужен только для проверок; сам ассистент по-прежнему запускается как самостоятельный HTML-файл.

До использования выводов при назначении необходимы сверка российских инструкций и независимый врачебный аудит. Текущий статус — рабочая экспериментальная версия для проверки на обезличенных случаях и сравнения с независимо принятым врачебным решением.
