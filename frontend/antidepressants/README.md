# Ассистент выбора антидепрессантов

Автономный врачебный прототип версии 0.2. Снимок клинической базы: 30.09.2026.

## Запуск

Скачайте `antidepressant-assistant.html` и откройте его в современном браузере. Сервер, сборка и установка зависимостей не нужны. Просмотр HTML на странице GitHub показывает исходный код; для запуска нужен скачанный файл.

## Возможности

- Кликабельный список незаполненных данных открывает соответствующий раздел формы.
- При депрессии: выбор основного руководства (КР РФ, NICE, VA/DoD, CANMAT), тяжесть эпизода, выраженность симптомов и главные мишени.
- История нескольких курсов: препарат, диагноз, эпизод, доза, длительность, приверженность, адекватность, ответ и нежелательные эффекты.
- Раздельные объяснения места в терапии, симптомных аргументов, рисков и индивидуального опыта; различия руководств показаны отдельно.
- Дополнительные маршруты для ГТР, панического расстройства, ОКР и ПТСР.
- Импорт и экспорт JSON, печать, учебные примеры, источники и журнал правил.

## Интерпретация

Частичный порядок опций — проектное правило без суммы баллов и без прогноза вероятности ремиссии. Противопоказания имеют приоритет над благоприятным совпадением симптомов. Инструмент не рассчитывает дозы, переходы, комбинации и полный набор взаимодействий. КР и инструкции конкретного препарата необходимо сверять отдельно.

Прототип не прошёл клиническую валидацию. В предыдущей разработке выполнены проверки клинических сценариев и модели DOM; проверка в настоящем браузере остаётся невыполненной. При переносе в этот репозиторий проверены синтаксис встроенного JavaScript и точное совпадение содержимого HTML.

## Клинические данные

Профили не передаются в сеть и автоматически не сохраняются. Данные существуют в памяти страницы; экспорт JSON выполняется явно пользователем. Экспортированные клинические профили не следует добавлять в репозиторий. Внешние ссылки на источники открываются отдельно.
