# PsyDraft и Клинический компас — один HTML

Рабочая экспериментальная версия 0.4. Не является зарегистрированным медицинским изделием; клиническое тестирование и валидация не пройдены. Решение принимает только врач под свою профессиональную ответственность.

## Запуск

Скачайте `antidepressant-assistant.html` и откройте в современном браузере. Установка, сервер и интернет не нужны. В файле две вкладки: **PsyDraft** для осмотра, заключения и клинических шкал и **Клинический компас** для обсуждения опций. Состояние вкладок сохраняется при переключении и восстанавливается при повторном открытии, если браузер разрешает локальное хранение для этого файла.

## Рабочий порядок

1. В PsyDraft заполните диагноз с кодом МКБ-10 и структурированные поля статуса.
2. В блоке «Данные для клинического компаса» укажите возраст и недостающие ограничения, лекарства и курсы терапии. Подтвердите полноту врачебной оценки.
3. Перейдите в компас: диагноз, возраст, симптомы, риски и история подставятся автоматически. Выберите тяжесть и главные мишени. Если исходные сведения неполны, компас покажет, что ещё требуется уточнить.
4. Для нового пациента используйте **«Новый случай»**: после подтверждения очищаются обе вкладки. Изменение возраста или диагноза также сбрасывает выбранные в компасе тяжесть и мишени.

Сон, аппетит, тревога и когнитивные жалобы переносятся из статуса. Ангедония и утомляемость отмечаются в разделе настроения, боль — в разделе ощущений, гиперсомния и нарушения стула — в разделе сна и аппетита. Верхнего дублирующего списка симптомов нет. Эти отметки также включаются в текст консультации. Суицидальные планы, БАР и признаки кататонии/выбранные галлюцинации переводят компас в специализированный маршрут. Отрицательная оценка БАР или психоза требует явного врачебного ввода; отсутствие отметки не считается отрицательным результатом.

Свободный текст анамнеза лечения показывается как справка. Он не преобразуется автоматически в адекватные курсы. Для их учёта заполните структурированные строки: препарат, диагноз курса, эпизод, доза, длительность, приверженность, адекватность, ответ и нежелательный эффект.

Нозология переносится только из поля «Диагноз (шифры МКБ-10)», включая выбор из поиска МКБ и добавление из нозологического советника. Первый код задаёт основной маршрут; неподдерживаемый основной диагноз не заменяется сопутствующим. Чтобы изменить основной диагноз, измените порядок кодов в этом поле. БАР имеет приоритет над автоматическим переносом депрессивного маршрута. Тяжесть и главные мишени остаются ручным выбором врача.

## Исправления логики

- Положительное уточнение сердечного, офтальмологического или урологического фактора не исчезает при снятии общего флажка: несогласованность блокирует список до уточнения.
- Все исторические нежелательные эффекты учитываются как множество. Перестановка курсов не меняет приоритеты.
- Сохранены ограничения ТЦА при тяжёлых заболеваниях печени и кардиальных противопоказаниях, ограничения кломипрамина при глаукоме/задержке мочи и возрастное ограничение агомелатина.
- Дисклеймер отображается один раз в общей оболочке.
- Внутренние якорные ссылки переписаны на `about:srcdoc#…`; обработчик прокручивает раздел внутри вкладки и сохраняет форму. Это устраняет попытку загрузить внешний документ в iframe при клике по боковой или нижней навигации.
- Каждая вкладка имеет отдельный документ и изолированные стили/скрипты. Обмен данными выполняется локально с проверкой источника сообщения и идентификатора сессии.

## Сохранение данных

Общий случай автоматически сохраняется локально в одном ключе `psydraft.case.v1`: осмотр, заключение, шкалы и их история, структурированные курсы терапии, ручная тяжесть и мишени Компаса. Данные не отправляются в сеть. Изолированные вкладки сохраняют исходную sandbox-защиту; оболочка проверяет источник, токен сессии, идентификатор случая и предыдущую версию записи. Индикатор подтверждает сохранение после успешной записи; отказ хранилища или конфликт другой вкладки показывается явно. При сбросе оболочка сразу записывает новый пустой случай, поэтому старая вкладка не может вернуть предыдущего пациента.

Кнопка JSON в компасе сохраняет **только профиль компаса**, не полный осмотр PsyDraft. Отдельный импорт профиля и учебные примеры в объединённом режиме скрыты, чтобы не подменять пациента, связанного с PsyDraft. В самостоятельном `src/compass.html` эти функции доступны. Внешние ссылки на источники открываются отдельно.

Шкалы доступны внутри PsyDraft; их результаты не участвуют в автоматическом выборе диагноза, тяжести или мишеней Компаса. Подключены полные SOPS, BNSS, CDSS и пожизненная C-SSRS в редакциях опубликованных КР, а также отдельный скрининг C-SSRS Recent. Для SPI-A доступна явно обозначенная критериальная форма COGDIS/COPER; это не полное книжное интервью. Старые оценки сохраняют исходную редакцию и не переименовываются в новые интервью. Подробности и источники — в [основном README](../../README.md#клинические-шкалы).

## Сборка

```bash
python3 frontend/psychstatus/build.py
python3 frontend/antidepressants/build.py
```

Дополнительно разработчик может запустить проверки на Node.js без установки пакетов:

```bash
node frontend/antidepressants/tests/engine-regression.test.cjs
node frontend/antidepressants/tests/combined-contract.test.cjs
node --test frontend/psychstatus/tests/*.test.cjs
node --test frontend/antidepressants/tests/case-storage.test.cjs frontend/antidepressants/tests/scales-bundle.test.cjs
```

Node.js нужен только этим необязательным тестам; для сборки и работы приложения не требуется.

Вторая команда сборки использует собранный PsyDraft и исходники из `src/`, записывает единый `antidepressant-assistant.html`. Только Python 3; npm и внешних библиотек нет.

## Проверки

Проверки охватывают безопасность движка, перенос и согласованность клинических данных, модель DOM / асинхронный обмен, хранение общего случая, шкалы, сравнение снимков и печатные листы. Проверяются все внутренние ссылки PsyDraft, расположение и перенос симптомов, добавление/удаление диагноза через советник и выбор из поиска МКБ. Дополнительно воспроизведённые дефекты скрытого риска и порядка курсов проверены после исправления. Результаты текущего прогона и границы ручной приёмки записаны в [IMPLEMENTATION_STATUS.md](../../docs/clinical-scales/IMPLEMENTATION_STATUS.md). Это программные проверки, не клиническая валидация.

Для браузерного запуска регрессий из каталога `frontend/antidepressants`:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/tests/safety-scenarios.html`. Проверяются самостоятельный движок и преобразование данных. Полная ручная проверка вкладок, копирования, печати и узкого окна описана в `tests/integration-manual.md` и ещё требует выполнения в настоящем браузере.

Доказательная база — КР РФ, NICE, VA/DoD, CANMAT и перечисленные инструкции. Приоритеты являются проектным частичным порядком без вероятности ремиссии или суммы баллов. Перед использованием выводов при назначении необходимы сверка российских инструкций и независимый врачебный аудит.
