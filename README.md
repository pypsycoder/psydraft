# PsyDraft — Шаблон амбулаторной консультации психиатра

> Интерактивный офлайн-инструмент для подготовки психиатрических консультаций

## О проекте

**PsyDraft** — это веб-приложение для психиатров, которое помогает структурированно собирать клинические данные и автоматически формировать текст заключения. Инструмент работает полностью офлайн, запускается в любом современном браузере и не требует серверных зависимостей.

### Ключевые возможности

- **Сбор клинических данных** — структурированные формы для жалоб, анамнеза жизни и болезни
- **Оценка психического статуса** — 10 подразделов с детализированными параметрами (сознание, мышление, восприятие, память, внимание, настроение, сон, аппетит и др.)
- **Нозологический советник** — автоматический анализ статуса и подсказка диагнозов по МКБ-10
- **Полный справочник МКБ-10 раздел F** — поиск и выбор из 430+ психиатрических диагнозов (весь раздел F)
- **Библиотека рекомендаций** — 30+ готовых рекомендаций по категориям с персистентным сохранением выбора
- **Управление назначениями** — гибкие схемы приёма препаратов с автодополнением названий
- **Генерация заключения** — автоматическое формирование итогового текста

## Клинические шкалы

Раздел **«Клинические шкалы»** после психического статуса содержит пять самостоятельных вкладок. Ответы начинаются с «Не оценено»; незавершённые оценки не включаются в заключение. Завершённая оценка появляется в блоке «Результаты психометрического обследования» перед диагнозом, если врач оставил включение активным. После первой генерации заключения изменение шкалы обновляет только этот блок, сохраняя остальной текст и отдельное дополнение врача.

Текущий объём реализации:

- **SOPS:** все 19 описаний и 133 оценочных якоря из Г2 КР «Шизотипическое расстройство» 1073_1 (2026), четыре субшкалы и временные характеристики. Интервал врач задаёт явно. Полная оценочная SOPS из КР не выдаётся за весь протокол SIPS и не устанавливает синдром риска автоматически.
- **BNSS:** все 13 пунктов, вопросы и 91 якорь из Г4 тех же КР; шесть субшкал и два домена. Опечатки нумерации исправлены по авторской шкале 0–6 с явным журналом и сохранением исходных номеров. Обрыв одного якоря восстановлен по предыдущим КР РОП.
- **CDSS:** полный русский бланк из Г3 КР «Шизофрения» (2023): 9 пунктов, 36 якорей, инструкция и наблюдательная оценка пункта 9. Периоды исключений внутри пунктов сохранены; пункт 8 вызывает отдельное предупреждение.
- **C-SSRS:** полная форма из Г1 КР «Биполярное аффективное расстройство» 675_2 (2025): мысли за жизнь, интенсивность наиболее опасной идеи, виды поведения, количества и опасность истинных попыток. Тяжесть, интенсивность и поведение — отдельные показатели; NSSI не становится попыткой, общей суммы риска нет. Сохранён также официальный русский **Screen Version — Recent**. Пересмотр положительных сведений требует подтверждения и оставляет журнал. Форма «После последнего визита» не подменяется изменением периода опубликованного бланка.
- **SPI-A / COGDIS / COPER:** критериальная форма по авторским таблицам: 28 исходных феноменов в 14 группах, частота, клиническое подтверждение и давность первого появления; отдельные COGDIS/COPER без суммы. В КР полного интервью SPI-A нет; рабочая русская терминология критериальной формы не выдаётся за официальный полный перевод SPI-A.

20.10.2026 пользователь подтвердил разрешения и указал брать тексты из КР. Источники, редакции и исправления — в [журнале полных форм](docs/clinical-scales/full/). Старые записи ввода баллов и подготовительные заметки сохраняют прежнюю редакцию; новая форма начинается отдельной оценкой. Неизвестная версия не превращается автоматически в полное интервью.

Случай, ответы, комментарии, назначения, рекомендации и редактор сохраняются **локально в одном ключе `psydraft.case.v1`**. При недоступности автосохранения появляется предупреждение; конфликтующая старая вкладка не перезаписывает новый случай. «Новый случай» очищает текущего пациента, все шкалы и их историю. Снимки оценок неизменяемы; новая оценка получает отдельный идентификатор. Сопоставимые оценки можно сравнить с выбранным снимком. Доступны предварительный просмотр оценочного листа, печать, сохранение листа в самостоятельный HTML и локальный экспорт JSON. Экспорт может содержать клинические комментарии; он сохраняется на устройстве пользователя.

Модуль работает и в самостоятельном PsyDraft, и в [объединённом файле с Клиническим компасом](frontend/antidepressants/README.md). Оболочка объединённого файла хранит общий случай, структурированные курсы терапии и ручные настройки Компаса; изолированные вкладки получают доступ к сохранению через проверяемые сообщения. Успешное сохранение показывается после подтверждения записи. Баллы шкал не меняют диагноз, психический статус, тяжесть и терапевтические мишени Компаса.

## Быстрый старт

### Требования

- Python 3.x (для сборки)
- Современный браузер (Chrome, Firefox, Safari, Edge)

### Сборка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/pypsycoder/psydraft.git
cd psydraft

# Собрать проект
python frontend/psychstatus/build.py

# Открыть в браузере
open frontend/psychstatus/dist/psychstatus.html
```

Скрипт `build.py` обрабатывает директивы `<!-- INCLUDE ... -->` и собирает модульные исходники в единый HTML-файл.

## Использование

1. **Откройте** `frontend/psychstatus/dist/psychstatus.html` в браузере
2. **Заполните** секции по порядку (жалобы → анамнез → статус → диагноз)
3. **Выберите** рекомендации из библиотеки или добавьте свои
4. **Добавьте** назначения с дозировками и схемами
5. **Скопируйте** готовое заключение в медицинскую документацию

### Горячие клавиши

- Навигация по секциям через боковое меню
- Сворачивание/разворачивание групп через `<details>`
- Редактирование итогового текста прямо в результате

```javascript
    fullText: "Полный развёрнутый текст рекомендации"

```

## Предложения по улучшению

### Приоритет: Высокий

#### 1. Сохранение и загрузка сессий
**Проблема:** Данные хранятся только в LocalStorage и теряются при очистке браузера.
**Решение:** Добавить экспорт/импорт JSON-файлов сессий для надёжного хранения и переноса между устройствами.

```javascript
// Пример API
function exportSession() {
    const data = collectAllFormData();
    const blob = new Blob([JSON.stringify(data)], {type: 'application/json'});
    downloadFile(blob, `session_${Date.now()}.json`);
}
```

#### 2. Печать заключения
**Проблема:** Нет оптимизированного режима печати.
**Решение:** Добавить CSS для `@media print` и кнопку "Печать" с форматированием для A4.

#### 3. Валидация обязательных полей
**Проблема:** Можно сгенерировать пустое заключение.
**Решение:** Подсветка незаполненных обязательных полей перед генерацией отчёта.

### Приоритет: Средний

#### 4. История изменений (Undo/Redo)
Добавить возможность отмены последних изменений для защиты от случайных ошибок.

#### 5. Шаблоны заключений
Готовые пресеты для типичных случаев:
- Первичная консультация

#### 6. Автосохранение с индикатором
Периодическое сохранение (каждые 30 сек) с визуальной индикацией статуса.

#### 7. Тёмная тема
Альтернативная цветовая схема для работы в условиях низкой освещённости.

## Безопасность

- Все данные хранятся **локально** в браузере пользователя
- Никакие данные **не передаются** на внешние серверы
- Рекомендуется использовать на защищённых рабочих станциях
- При работе с персональными данными соблюдайте требования законодательства о защите ПДн
